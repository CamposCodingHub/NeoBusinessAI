# DAY_20260912 — Electronic signature stub (ClickSign-style)

Data: 12 de setembro de 2026

## Objetivo

Entregar um **stub pragmático** de envelopes de assinatura eletrônica (estilo ClickSign):
criar / listar / enviar / marcar assinado — **sem** provedor real.

## Escopo explícito (o que NÃO é)

| Não incluso | Motivo |
| --- | --- |
| Integração ClickSign / DocuSign / Adobe Sign | Stub local apenas |
| Certificado ICP-Brasil | Sem PKI |
| Webhooks de provedor | Sem `external` callbacks reais |
| Envio de e-mail real | Status machine só |

## Entrega

### Backend — model (`database.py`)

| Model | Campos |
| --- | --- |
| `ESignEnvelope` | `id`, `user_id`, `document_id` (nullable), `title`, `status` (`draft`\|`sent`\|`signed`\|`cancelled`), `signer_email`, `signer_name`, `provider` (default `stub`), `external_id` (nullable), `created_at`, `signed_at` (nullable) |

### Backend — routes (`routes/esign_routes.py`)

JWT via `get_current_user`. Envelopes filtrados por `user_id` (IDOR → **404**).

| Método | Path | Função |
| --- | --- | --- |
| `POST` | `/esign/envelopes` | Cria envelope (`draft`) |
| `GET` | `/esign/envelopes` | Lista envelopes do user |
| `POST` | `/esign/envelopes/{id}/send` | Stub → `sent` (+ `external_id`) |
| `POST` | `/esign/envelopes/{id}/mark-signed` | Stub → `signed` (+ `signed_at`) |

Registrado em `main.py` (`esign_router`).

### Frontend

| Item | Detalhe |
| --- | --- |
