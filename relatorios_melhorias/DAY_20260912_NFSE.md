# DAY 2026-09-12 — NFS-e stub

## Goal
Local draft / issue-stub flow for NFS-e **without** calling any prefeitura API.

## Deliverables

| Path | Role |
|------|------|
| `NfseDraft` model (`database.py`) | draft \| issued_stub \| cancelled |
| `POST /billing/nfse` | Create draft (JWT) |
| `GET /billing/nfse` | List drafts (JWT) |
| `POST /billing/nfse/{id}/issue-stub` | Sets `issued_stub` + `NFS-e-STUB-XXXX` |
| `backend/tests/test_nfse_stub.py` | 2+ tests |

## Stub only
