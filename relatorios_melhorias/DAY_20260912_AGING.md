# DAY 2026-09-12 — Receivables aging (BI light)

## Goal
JWT endpoint that groups unpaid invoices into aging buckets, plus a light UI on the finance dashboard.

## Deliverables

| Path | Role |
|------|------|
| `GET /finance/aging` | JWT; buckets from `Invoice` (`due_date` or `created_at`) |
| `frontend/app/dashboard/finance/page.tsx` | Aging bars (navy/teal) |
| `backend/tests/test_finance_aging.py` | ≥3 tests |

## Response shape
```json
{
  "buckets": {
    "current": 0.0,
    "d31_60": 0.0,
    "d61_90": 0.0,
    "d90_plus": 0.0
  },
  "total_open": 0.0,
  "currency": "BRL"
}
```

Open = status `pending` or `overdue`. Paid/cancelled excluded. Days = max(0, now − due_date|created_at).

## Tests
```bash
cd backend
python -m pytest tests/test_finance_aging.py -q
```

## Not in scope
Collections automation, export, multi-currency.
