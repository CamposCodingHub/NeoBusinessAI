# DAY_20260912 — Trust accounting stub (IOLTA-style)

Data: 12 de setembro de 2026

## Objetivo

Entregar um **stub pragmático** de ledger de valores em custódia (estilo IOLTA / client trust funds):
contas + lançamentos + saldo — **sem** integração bancária.

## Escopo explícito (o que NÃO é)

| Não incluso | Motivo |
| --- | --- |
| Integração bancária real | Fora do escopo deste stub |
| PIX / Open Finance / TED | Não há gateway nem conciliação |
| Movimentação de dinheiro real | Apenas livro-razão local |
| Compliance IOLTA completo | Sem reconciliação tripartite, sem interest accounting |

Isto é um **ledger interno** para o produto PMS/legal ops — útil para UX e modelo de dados — **não** um banco.

## Entrega

### Backend — models (`database.py`)

| Model | Campos |
| --- | --- |
| `TrustAccount` | `id`, `user_id`, `organization_id` (nullable), `name`, `currency` (default `BRL`), `created_at` |
| `TrustLedgerEntry` | `id`, `trust_account_id`, `client_id` / `matter_id` (nullable), `entry_type` (`deposit`\|`withdrawal`\|`transfer`\|`adjustment`), `amount` (Float), `memo`, `created_at`, `created_by_user_id` |

### Backend — routes (`routes/trust_routes.py`)

JWT via `get_current_user`. Contas filtradas por `user_id` (IDOR → **404**).

| Método | Path | Função |
| --- | --- | --- |
| `POST` | `/trust/accounts` | Cria conta |
| `GET` | `/trust/accounts` | Lista contas (+ balance) |
| `POST` | `/trust/accounts/{id}/entries` | Lança entrada |
| `GET` | `/trust/accounts/{id}/ledger` | Lista lançamentos |
| `GET` | `/trust/accounts/{id}/balance` | Saldo |

**Fórmula de saldo:** `deposits − withdrawals − transfers (+ adjustments)`.

`transfer` é tratado como **transfer out** (reduz saldo) neste stub.

Registrado em `main.py` (`trust_router`).
